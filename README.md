# Color Tuft

A free, open-source web app that turns flat artwork into a tuftable rug pattern: reduced to a few yarn colours, cleaned up for tufting, with yarn amounts, and projected at true size onto the tufting cloth.

Runs entirely in the browser. No accounts, no server; images never leave your device.

**Status:** early prototype, not usable yet.

## Development

```sh
npm install
npm run dev
```
